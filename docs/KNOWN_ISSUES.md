# 待修复问题

## D001：主动下载提示“音频校验失败，请重试”

来源：用户在真实 Mac 上反复复现；本轮云端尚未复现账号相关的下载请求。范围包括单曲及批量主动下载。不能由此推断在线播放缓存、AutoMix 模型或音轨分离缓存也有同样问题。

本轮已在源码中隐藏主动下载入口，不删除 DownloadManager、底层音频缓存或既有用户文件，不迁移登录、偏好或数据身份。隐藏 UI 不代表校验机制已经修好。实际构建与验收状态见 PR #3。

后续修复应核对响应状态、实际音频格式与文件内容、完成长度、校验规则和重试行为；以合成或获授权的测试素材回归，日志不记录账号、认证头或私人音乐库信息。恢复下载入口之前，需要验证单曲、批量、取消、重试与已存在文件保护。

## D002：暂停、恢复及直接切歌瞬间偶发 Click/Pop

用户在 CI #13 的真实 Mac 测试中报告：Hi-Res/无损歌曲中等振幅片段较容易听到极短瞬态，低音量段较少，渐进 AutoMix 交接较不明显。没有同时发生位置跳跃、进度或歌词错位。用户已完成 13 项媒体时间线及压力使用验收，因此继续保留 `a57693c` 的时钟基线。

非零振幅截断、突入、gain 跳变、DSP 状态切换都只是待验证假设。使用原创合成 PCM 定位源、效果链与最终输出边界；不提交私人歌曲、音乐库或截图。极短去爆音包络只有在实际渲染证明生效、媒体样本无跳漏/重复、响应延迟合理且完整回归通过后才能作为修复报告。CI 或听感未证实前保持此问题开放。

[实际 PCM 边界测量与修复边界](QIETING_CONTROL_BOUNDARIES.md)：已观察到暂停/恢复的非零波形与静音突变，D002 尚未集成生产修复。
