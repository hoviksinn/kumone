# 待修复问题

## D001：主动下载提示“音频校验失败，请重试”

来源：用户在真实 Mac 上反复复现；本轮云端尚未复现账号相关的下载请求。范围包括单曲及批量主动下载。不能由此推断在线播放缓存、AutoMix 模型或音轨分离缓存也有同样问题。

本轮计划暂时隐藏主动下载入口，不删除 DownloadManager、底层音频缓存或既有用户文件，不迁移登录、偏好或数据身份。隐藏 UI 不代表校验机制已经修好。实现与最终 CI 状态见 PR #3。

后续修复应核对响应状态、实际音频格式与文件内容、完成长度、校验规则和重试行为；以合成或获授权的测试素材回归，日志不记录账号、认证头或私人音乐库信息。恢复下载入口之前，需要验证单曲、批量、取消、重试与已存在文件保护。
